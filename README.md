# nextjs-preset
## `minimal-preset`
**A Minimal Preset** with **the latest software installed** and **a clean showcase of the software versions**, which **replaces the** cluttered **default Vercel Landing Page**.

## `shop-preset`
**A Storefront Preset** with **clean UI**, **latest software installed**, **ready for you** to **plug-in a database and auth**.

## `product-lp-preset`
**A Product Landing Page Preset** with a **clean**, **simple UI**, **latest software**, and **a clean config file** you can **tweak as needed**.
