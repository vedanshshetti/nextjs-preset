# nextjs-preset

A collection of clean, modern Next.js presets designed for real-world projects.  
Each preset ships with **TS 6.0.3**, **latest dependencies**, and **zero clutter**.

---

## `minimal-preset`
A **Minimal Starter** with the **latest software installed** and a **clean version showcase**.  
Perfect for cloning and jumping in — replaces the default Vercel landing page with something actually usable.

---

## `shop-preset`
A **Storefront Starter** with a **clean UI**, **modern tooling**, and a structure that’s **ready for database + auth integration**.  
Ideal for e‑commerce, product catalogs, or any project that needs a frontend + backend foundation.

---

## `product-lp-preset`
A **Product Landing Page Starter** with a **simple**, **clean UI**, **modern dependencies**, and a **config file you can tweak instantly**.  
Great for SaaS landing pages, product showcases, or marketing sites.

---

### ⚠ TypeScript Version Notice
All presets use **TypeScript 6.0.3**.  
Next.js does not fully support TypeScript 7 yet — upgrade at your own risk.
